# Supervised Learning Project Report

## 1. Introduction

This project demonstrates supervised machine learning using both regression and classification techniques.

The project implements:
- Linear Regression for a regression problem
- Logistic Regression for classification
- Decision Tree Classifier for classification

The objective is to train machine learning models, evaluate their performance, and compare the results.

---

## 2. Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
